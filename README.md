# Tower of Hanoi Solver

![Ilustrasi Tower of Hanoi](image_e60164.png)

## Deskripsi
Repositori ini berisi implementasi penyelesaian masalah **Tower of Hanoi** menggunakan bahasa pemrograman Python. Program secara otomatis menghitung dan mencetak langkah-langkah yang diperlukan untuk memindahkan susunan disk dari tiang awal (Tiang A) ke tiang tujuan (Tiang C) sesuai dengan gambar referensi.

## Aturan Permainan
Penyelesaian masalah mematuhi tiga aturan dasar berikut:
1. Hanya satu disk yang dapat dipindahkan pada satu waktu.
2. Setiap perpindahan melibatkan pengambilan disk teratas dari salah satu tiang dan meletakkannya di atas tiang lain.
3. Disk yang lebih besar tidak boleh diletakkan di atas disk yang lebih kecil.

## Cara Menjalankan Program
Pastikan Python sudah terinstal di sistem, lalu jalankan file script melalui terminal:

```bash
python tower_of_hanoi.py
